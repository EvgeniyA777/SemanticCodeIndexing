# Vendored `scip.proto`

`scip.proto` in this directory is a verbatim copy of the SCIP protobuf schema
from Sourcegraph's `scip` repository. It is the committed source of truth for
the JVM SCIP reader (`semidx.runtime.scip`) used by the plans/018 semantic
provider authority migration (Stage 3, TypeScript SCIP vertical slice).

## Why `v0.5.2`

- It is the last tag published under the `github.com/sourcegraph/scip` package
  namespace. `v0.9.0` renamed the Go/Java package options to `scip-code/scip`
  (`option java_package = "org.scip_code.scip"`) after the project moved.
- It is field-compatible with the schema bundled inside
  `@sourcegraph/scip-typescript@0.4.0` (the pinned indexer in
  `scripts/scip-toolchain/`): both carry `Document signature_documentation = 7`,
  `string enclosing_symbol = 8`, `repeated Relationship relationships = 4`, and
  the `SymbolRole` set up to `ForwardDefinition = 0x40`. `v0.9.0` changed field
  7 to a `Signature` message, which would misparse any `signature_documentation`
  emitted by the pinned indexer.
- SCIP wire encoding is append-only and field numbers are stable, so a `.scip`
  artifact produced by `scip-typescript@0.4.0` deserializes cleanly against this
  schema.

## No local edits

The file is byte-identical to upstream. It carries no `option java_package`, so
generated Java lands in package `scip` with outer class `Scip` (single-file,
`java_multiple_files` is unset upstream). Do not patch the vendored file; if the
Java package placement needs to change, record the decision here and in the
plans/018 progress log first.

## Regeneration

Java stubs are generated by the repo-managed protobuf toolchain (ADR-042):

```
clojure -T:build grpc-generate          # regenerates src-generated/java for all pinned .proto files
clojure -T:build grpc-verify-generated  # fails on drift between committed stubs and the pinned toolchain
```

To refresh this file from a new upstream tag, replace it with the verbatim
upstream `scip.proto`, update the table and SHA-256 above, re-run
`grpc-generate`, and re-verify the SCIP reader round-trip tests.
